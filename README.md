#  Proyecto: Feliz Día de las Madres - Mamita Irene

Este es un proyecto web interactivo diseñado como regalo personalizado para el Día de la Madre. La aplicación guía al usuario a través de una experiencia emotiva que incluye una pantalla de bienvenida, una galería de fotos tipo film, un monitor de video decorado y una carta digital.

##  Características

* **Pantalla de Inicio Estilo Polaroid:** Una bienvenida con animaciones suaves y una foto principal con efecto de "flotado".
* **Navegación Interactiva:** Menú de opciones visuales para explorar diferentes contenidos.
* **Carrusel de Recuerdos:** Un slider infinito de fotos y videos que se desplaza automáticamente y se puede pausar al pasar el mouse.
* **Monitor de Video:** Una sección que simula una pantalla decorada con moños y guirnaldas para reproducir un video especial.
* **Carta Digital:** Una interfaz que simula una ventana de "Nuevo Mensaje" con un texto dedicado y un botón de envío con alerta interactiva.
* **Ambiente Musical:** Sistema de reproducción de música de fondo automática (requiere interacción inicial del usuario).
* **Diseño Responsivo:** Adaptado para visualizarse correctamente en computadoras, tablets y teléfonos móviles.

## 📁 Estructura del Proyecto

El proyecto está organizado de la siguiente manera:

* `index.html`: Punto de entrada principal con la bienvenida y el menú de opciones.
* `carusel.html`: Galería infinita de imágenes y videos.
* `video.html`: Sección dedicada a la reproducción de un video especial.
* `carta.html`: Mensaje escrito dedicado a "Mamita Irene".
* `script.js`: Lógica para la navegación entre pantallas, alertas y control de animaciones/música.
* `styles.css`: Estilos globales y animaciones de las pantallas principales.

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura de las páginas y contenedores de multimedia.
* **CSS3:** Flexbox, Grid, Animaciones (`@keyframes`) y Media Queries para el diseño responsivo.
* **JavaScript (Vanilla):** Manipulación del DOM para transiciones y eventos de usuario.

## 📝 Notas de Configuración

Para que el proyecto funcione correctamente, asegúrate de tener las siguientes carpetas en el directorio `assets/`:
1.  `/img/`: Para las fotos de la Polaroid, flores y decoraciones.
2.  `/video/`: Para los clips de video MP4.
3.  `/musica/`: Para el archivo de audio de fondo.
4.  `/css/`: Para los archivos de estilos específicos de cada sección.
